# Дела

Локальное приложение для личных задач. Данные находятся в браузере и не синхронизируются между устройствами.

## Запуск

Установите Node.js версии из `.nvmrc` (`nvm use`) и включите Corepack (`corepack enable`). Версия Yarn закреплена в `packageManager`.

```sh
yarn install
yarn dev
yarn typecheck
yarn lint
yarn format:check
yarn test
yarn build
```

Для публикации статического сайта настройте возврат `index.html` для клиентских маршрутов; иначе прямое открытие `/calendar` и других страниц приведёт к ошибке сервера.

Даты и время задач трактуются как местные календарные значения устройства, без преобразования в UTC. При смене часового пояса они остаются теми же местными датой и временем. Напоминание показывается однократно, только пока приложение открыто и браузер разрешает уведомления; при приостановке вкладки оно может задержаться. Удалённые задачи сохраняются до окончательного удаления пользователем.
